# Random-Game

Random-Game
Description

Random-Game is a Java-based game project that features different character classes, including Warrior, Mage, Archer, and Healer. Each character has a unique role and abilities, making the game more interesting and interactive.

Features
Different character types with unique roles.
Character management using Java classes.
A graphical user interface for player interaction.
Object-oriented programming concepts such as inheritance and encapsulation.
Project Files
Main.java – Starts the application.
GameCharacter.java – Defines the base character class.
Warrior.java – Defines the warrior character.
Mage.java – Defines the mage character.
Archer.java – Defines the archer character.
Healer.java – Defines the healer character.
CharacterManager.java – Manages game characters.
CharacterGUI.java – Provides the graphical user interface.
Technologies Used
Java
Object-Oriented Programming (OOP)
Java GUI
How to Run
Clone or download this repository.
Open the project in a Java IDE, such as IntelliJ IDEA, Eclipse, or NetBeans.
Compile the Java files.
Run Main.java to start the application.
